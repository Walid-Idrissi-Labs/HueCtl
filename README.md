# HueCtl

HueCtl is a lightweight, mobile-friendly web application designed to transform your phone's screen into a versatile light source. By providing a simple interface to adjust the color temperature of your display, HueCtl helps you illuminate environments and surfaces, making it perfect for reading at night or creating a gentle ambient glow.

## What it Does

- **Customizable Color Temperature:** Easily adjust your screen's light output from a warm, cozy **1500K** to a crisp, cool **9000K**.
- **Real-time Feedback:** The entire screen background updates instantly as you move the slider, providing an immersive lighting experience.
- **Persistence:** Your preferred color temperature is automatically saved, so it's ready for you the next time you open the app.
- **Minimalist Design:** A clean, distraction-free interface that focuses on providing the best possible light source.
